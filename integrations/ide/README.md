# GenOS Studio IDE integrations

All clients share [`genos-extension-contract.json`](./genos-extension-contract.json). The VS Code adapter is loadable as an extension folder; JetBrains and Antigravity consume the same command IDs and HTTP contract. Configure the API base in VS Code with `genos.apiBase` (default `http://localhost:4000/api`).
