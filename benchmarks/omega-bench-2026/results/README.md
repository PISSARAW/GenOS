# Résultats

Les qualifications publiques A, B et C du corpus v0.3.0 sont décrites dans
`AB-adapter-qualification-2026-10-27.md` : 3 400 cas × 3 répétitions, soit
10 200 résultats par condition, tous conformes à l'oracle indépendant.
B et C réutilisent les handlers de référence sur la plupart des expériences;
C ne mesure qu'une passe de fusion ciblée sur E04. Ces résultats qualifient le
raccordement des adaptateurs, pas un gain comparatif.

Le pilote E03 compare AJV 2020-12 au validateur Omega Node. Les probes de
services GenOS pour D sont consignés dans
`D-service-contract-probes-2026-10-27.md`; ils ne constituent pas une exécution
de la condition D. D, les baselines externes, les ablations, le holdout scellé
et l'analyse statistique confirmatoire restent à faire.
