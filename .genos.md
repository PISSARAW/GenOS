RÈGLES STRICTES DE GÉNÉRATION DE CODE :
1. Complexité cyclomatique faible : Gardez un code lisible et direct.
2. 3 paramètres maximum par fonction (sauf indication explicite contraire).
3. Respect absolu des principes SOLID.
4. Fichiers de 400 lignes maximum (sauf indication explicite contraire).
5. Violation de l'architecture sans ADR (Architecture Decision Record) interdite.
Toute violation de ces règles entrainera un rejet par l'Arbitre de Réalité.

Le gate executable est `scripts/ci/check_code_quality.py` : il refuse tout fichier
source de plus de 400 lignes, toute fonction de plus de 3 parametres et toute
fonction de complexite cyclomatique superieure a 10. Le hook `.githooks/pre-commit`
autorise un commit documentation-only; des qu'un fichier de code est staged, il
controle tout le code versionne. La CI controle egalement tout le code versionne.
Les fichiers de documentation sont hors de ce perimetre. Aucune annotation dans
un fichier de code ne permet de contourner le gate.
