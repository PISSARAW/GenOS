# Agent manifest examples

These fixtures show the YAML and JSON forms of small agent definitions:

- `classic-local-agent.yaml` — a provider-agnostic local assistant;
- `demo_agent.yaml` — the minimal demo agent;
- `genos-native-agent.json` — the equivalent native-runtime JSON form.

They are examples, not generated runtime state. Copy a fixture before adapting
identities, policies, or tool permissions for a real workflow.
