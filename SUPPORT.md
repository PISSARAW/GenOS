# Support

GenOS is an experimental open source project maintained on a best-effort basis.

## Where to ask

- Use a GitHub issue for a reproducible bug or a concrete feature proposal.
- Use GitHub Discussions, when enabled, for design questions, usage help, and broader ideas.
- Use the security process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Before posting, search existing issues and read the [documentation index](docs/README.md). Include the GenOS revision, operating system, Rust version, command or manifest, expected behavior, actual behavior, and the smallest safe reproduction.

## What support does not include

There is currently no guaranteed response time, commercial support contract, production SLA, or compatibility commitment for pre-alpha releases. Maintainers may close requests that cannot be reproduced, omit necessary context, expose sensitive data, or fall outside the project's scope.
