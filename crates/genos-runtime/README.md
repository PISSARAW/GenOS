# genos-runtime

`genos-runtime` contains the execution engine for GenOS agents and branches.

## Responsibilities
- **Evolution**: Handles agent breeding, heredity, and genetic algorithms for agent models.
- **Causal Replay**: Enables strictly deterministic replays of agent actions and observations.
- **Cognitive Merge**: Provides mechanisms to merge knowledge bases across distinct branches.
- **Scientific**: Contains utilities for hypothesis testing and rigorous experimentation tracking.
- **Security**: Security co-evolution pipelines and isolation checks.
