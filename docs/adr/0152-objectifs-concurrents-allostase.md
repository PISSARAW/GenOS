# ADR 0152 — Objectifs concurrents et allostase

Les objectifs portent poids, valeur et invariants minimaux. Les politiques
sont comparées sur une utilité pénalisée par la pression allostatique; une
violation d’invariant reste visible même si l’utilité est élevée. La pression
est mise à jour par l’erreur observée avec un gain borné.
