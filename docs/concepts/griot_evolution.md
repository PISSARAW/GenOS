# L'Évolution et l'Hérédité chez GenOS

Griot n'est pas statique. À mesure qu'il accomplit des tâches, il accumule de l'expérience, de nouveaux prompts optimisés et des instructions spécifiques au projet. Plutôt que de réapprendre à chaque fois, il utilise l'hérédité biologique.

## 1. Transfert Horizontal de Gènes (Plasmides)
Les agents peuvent s'échanger des "plasmides" (blocs de code, de contexte ou de règles). Si Griot_A a découvert comment contourner un bug rare, il package cette information dans un plasmide et le transfère à Griot_B.
* **Outil MCP** : `genos_evolution_assimilate_plasmid`

## 2. Spéciation
Lorsque Griot s'adapte très profondément à une base de code (par exemple, un backend Rust très complexe), son génome diverge de sa configuration d'origine. S'il diverge trop (`divergence_threshold > 0.8`), il devient une nouvelle "espèce" d'agent, hyper-spécialisée, incapable de travailler sur du Frontend, mais imbattable sur le Backend.
* **Outil MCP** : `genos_biomimicry_speciation_check`
