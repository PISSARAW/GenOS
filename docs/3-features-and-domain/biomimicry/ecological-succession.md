# Succession Écologique — Déploiement Graduel

> **Concept** : Un écosystème se construit par vagues : les espèces Pionnières préparent le terrain pour les Intermédiaires, qui stabilisent le milieu pour les espèces Climax.
> **Statut** : implémenté (genos-core::biomimicry::ecological_succession)

## Bénéfice
Plutôt que d'envoyer un agent "Pro" sur un projet vierge (trop lent, trop cher), l'essaim déploie d'abord des agents Pionniers (Flash, haute température, robustes) pour cartographier le code. Une fois la coverage suffisante, l'essaim déclenche les Intermédiaires. À haute stability, il passe en phase Climax (agents ultra-spécialisés de maintenance).
