# Rythmes Circadiens — Chronobiologie

> **Concept** : Horloges internes dictant des phases distinctes (éveil vs sommeil) pour optimiser l'allocation d'énergie.
> **Statut** : implémenté (genos-core::biomimicry::circadian_rhythms)

## Bénéfice
Bascule l'essaim entier entre Diurnal (requêtes live, réactivité max) et Nocturnal (maintenance lourde, Garbage Collection, Replay Hippocampique).
