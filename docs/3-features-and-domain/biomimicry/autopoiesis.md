# Autopoïèse — Viabilité Autonome

> **Concept** : Un système vivant est capable de se reproduire et de se maintenir par lui-même (Varela & Maturana).
> **Statut** : implémenté (genos-core::biomimicry::autopoiesis)

## Bénéfice
Un essaim évalue sa propre *viabilité*. S'il n'a plus les ressources pour s'auto-maintenir (budget faible, taux d'erreur critique), il alerte l'humain avant de s'effondrer.
