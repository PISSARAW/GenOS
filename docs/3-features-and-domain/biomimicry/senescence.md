# Sénescence Cellulaire — Purge des Zombies

> **Concept** : Les vieilles cellules cessent de se diviser pour éviter les mutations (cancers), puis sont purgées.
> **Statut** : implémenté (genos-core::biomimicry::senescence)

## Bénéfice
Détecte et tue gracieusement les agents "zombies" qui tournent depuis trop d'epochs sans résultats, libérant ainsi la mémoire et le compute global.
