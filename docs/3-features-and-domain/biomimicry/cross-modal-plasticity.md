# Plasticité Cross-Modale

> **Concept** : Le cerveau réaffecte les aires sensorielles mortes (ex: cortex visuel chez un aveugle) à d'autres sens (toucher, ouïe).
> **Statut** : implémenté (genos-core::biomimicry::cross_modal_plasticity)

## Bénéfice
Si une API tombe (ex: web_search), l'agent ré-affecte organiquement cette dépendance vers un outil de substitution (ex: local_rag_index) sans crasher.
