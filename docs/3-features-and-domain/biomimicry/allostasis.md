# Allostasie — Anticipation Prospective

> **Concept** : Contrairement à l'homéostasie (réactive), l'allostasie anticipe les besoins avant qu'ils ne surviennent (ex: suer avant d'avoir chaud).
> **Statut** : implémenté (genos-core::biomimicry::allostasis)

## Bénéfice
Pré-alloue massivement des budgets de compute/tokens avant un pic de charge prévu, évitant les congestions de file d'attente (stress anticipation).
